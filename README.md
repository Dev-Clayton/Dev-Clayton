## 👩‍💻 Sobre mim

Meu nome é **Clayton Modder**.

Sou desenvolvedor **Full Stack** com formação técnica em Informática e atualmente graduando em **Análise e Desenvolvimento de Sistemas** pela **PUCRS**. Tenho experiência no desenvolvimento de aplicações web, APIs, sistemas desktop, automações e soluções voltadas à alta performance.

Minha principal motivação é criar softwares escaláveis, seguros e bem estruturados, utilizando boas práticas de arquitetura, código limpo e tecnologias modernas.
